AM4 DISPLAY SWIPE NAVIGATION UPDATE
====================================

Updated file:
  AM4_DISPLAY/AM4_UI.h

Gesture behavior:
  - Swipe RIGHT on the Dashboard page -> opens the Temperatures page.
  - Swipe LEFT on the Temperatures page -> returns to the Dashboard page.

Touch safeguards retained:
  - Minimum horizontal swipe distance: 55 pixels.
  - Horizontal movement must be greater than vertical movement.
  - Touch action debounce: 180 ms.
  - Existing bottom navigation tap fallback remains available.

Unchanged:
  - Complete AM4_HARDWARE_HOST project.
  - Wi-Fi AP/STA operation.
  - TCP JSON communication.
  - MQTT/mobile-app communication.
  - Sensor, pressure, alarm, and control logic.

Touch wiring:
  TFT SCK   -> GPIO18
  TFT MISO  -> GPIO19
  TFT MOSI  -> GPIO23
  TFT CS    -> GPIO15
  TFT DC    -> GPIO2
  TFT RST   -> GPIO4
  TOUCH CS  -> GPIO21

Board:
  DOIT ESP32 DEVKIT V1
