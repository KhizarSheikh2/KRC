AM4 MQTT JSON KEYS CONFIRMATION
================================

Exact topics
------------
Hardware -> app temperature configuration:
/KRC/AM4-AAA001/temperature_config_AM4

App -> hardware general configuration:
/test/AM4-AAA001/2

Hardware -> app live telemetry:
/KRC/AM4-AAA001

App -> hardware setpoints:
/test/AM4-AAA001/1

Other Sensor keys
-----------------
Temperature configuration:
- address6
- temp6
- dynamic DS18B20 address key with role value 6
- offset6

Live telemetry:
- othertemp       (Celsius value)
- othertempF      (Fahrenheit value)

Hardware -> display private link:
- otherC

The private display key is intentionally separate from the MQTT/mobile-app
telemetry contract. AM4 hardware sends otherC and AM4 display reads otherC.

JSON validity notes
-------------------
The firmware uses ArduinoJson, so generated payloads are valid JSON. Example
payloads must include a comma after dischargelinetemp and must not include a
trailing comma after the final field.
