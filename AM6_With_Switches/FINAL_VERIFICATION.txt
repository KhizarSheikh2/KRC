AM6 FINAL STABILITY RELEASE

Key fixes:
- Indoor physical controls: Fan 23/22/21, Heat-Cool 18, System Power 19.
- GPIO19 OFF requires 120 ms continuous LOW to reject electrical noise spikes.
- GPIO19 ON still requires 1500 ms stable HIGH before startup.
- Indoor RS485 B0 heartbeat 400 ms; one/multiple short misses do not immediately publish Power Fault.
- Outdoor status link offline requires 8 misses plus >=3500 ms since the last valid status.
- Outdoor slave master-command safety lease extended to 6000 ms, preventing network work from cycling relays.
- Explicit Indoor systemPower=0 still forces Outdoor OFF immediately when received.
- Outdoor PCF8574 I2C read failure gets a 300 ms communication-noise grace using last verified switch states.
- Sustained PCF failure still fails safe and turns relays OFF.
- Indoor AP health no longer restarts the SoftAP on a transient softAPIP/channel transition.
- Indoor STA recovery uses WiFi.reconnect() rather than repeated WiFi.begin() while Display is attached.
- Display reconnect no longer calls WiFi.disconnect() on each retry.
- Display UI preserves ONLINE through a brief radio transition while the last Indoor state is still fresh.
- RS485 protocol remains v3: 3-byte request, 46-byte dual-status response.

Host-side verification performed:
- Local physical switch production header harness: PASS
  * 50 ms power noise ignored
  * real OFF at 120 ms
  * ON qualification 1500 ms
  * mode/fan mappings and blank fan hold-last-speed
- Outdoor production IO.h stability harness: PASS
  * relay restart qualification
  * short I2C read miss does not cycle relays
  * 2 s heartbeat gap stays inside 6 s slave lease
  * sustained I2C failure fails safe OFF
- Dual status priority harness: PASS
- RS485 protocol v3 layout static assertions: PASS
- Indoor/Outdoor am6_rs485_protocol.h byte-for-byte identical: PASS

A full ESP32 PlatformIO compile/upload and physical electrical test must still be performed on the target boards.
