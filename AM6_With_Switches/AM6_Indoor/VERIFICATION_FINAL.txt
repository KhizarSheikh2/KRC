INDOOR MASTER AUDIT
- Physical GPIO19 power switch remains authoritative.
- OFF is immediate.
- ON requires 1500 ms stable HIGH qualification.
- Fan selector GPIO23/22/21 mapping remains LOW/MEDIUM/HIGH.
- GPIO18 remains 0=COOL, 1=HEAT.
- Blank/invalid fan selector holds last valid fan speed.
- localSwitchesInit() now runs only after Wi-Fi/server/MQTT setup so the startup qualification timer cannot be consumed while the controller is still initializing.
- MQTT socket timeout reduced from 5 s to 1 s to reduce the chance of starving the 500 ms Outdoor RS485 heartbeat during cloud reconnects.
- Physical power/fan/mode remain monitoring-only from MQTT; app cannot override them.
- Indoor services physical switches before RS485 in the main loop.

OUTDOOR SLAVE AUDIT
- RS485 loop is serviced before relay decisions.
- No relay can energize without a fresh Indoor B0 command lease.
- systemPower=0 or outdoorEnable=0 forces R1..R4 OFF.
- Master re-arm delay: 1500 ms.
- Circuit healthy restart delay: 1000 ms.
- Circuit A: SW1..SW4 -> R1/R3 -> statusout.
- Circuit B: SW5..SW8 -> R2/R4 -> statusoutB.
- Status priority: High PSI -> Low PSI -> Power Fault -> Overload/Tripped -> Running.
- Running requires the corresponding relay pair to be written/read-back ON.
- PCA9554 active-HIGH safe startup preloads relay bits LOW/OFF before output configuration.
- Relay writes are read back from PCA9554 before logical state is accepted.
